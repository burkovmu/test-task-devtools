# Тестовое задание: редирект при открытых DevTools

- `main.html` — главная, ссылка на `2.html`
- `2.html` — подключает `security.js`
- `security.js` — если DevTools открыты, редиректит на `main.html`

## Проверка

Открыть `main.html`, открыть DevTools и перейти по ссылке — должно вернуть на `main.html`. С закрытыми DevTools `2.html` открывается нормально. Если открыть DevTools уже на `2.html`, редирект тоже сработает.
